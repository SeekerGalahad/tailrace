# dev/ — Technical Decision Records

This directory holds **technical decision records** (TDRs) that document
why specific engineering choices were made — useful for contributors
understanding the codebase evolution.

## What belongs here

- Golden attribution tables (e.g., dependency upgrade byte-diff analysis)
- Architecture Decision Records (ADRs)
- Migration guides with before/after evidence

## What does NOT belong here

Internal process documents (project planning, review notes, release
verification reports) are maintained in the developer's private workflow
and are not part of the public repository.

The public roadmap is `docs/ASSESSMENT-AND-OUTLOOK.md` §五 (Future Outlook).
