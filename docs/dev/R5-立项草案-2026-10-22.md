## 〇、启动门（硬性，先于一切任务卡）

R5 任何代码动工前，R4 必须整体收口，三条件同时满足：

```bash
git tag -l v1.0.0                                          # 非空（T31 已 tag）
for c in $(bash scripts/release-crates.sh --list); do curl -sf https://crates.io/api/v1/crates/$c | grep -o '"max_version": *"1\.0\.0"'; done | wc -l   # = 21
```
